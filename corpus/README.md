# Local research corpus

Drop `.pdf`, `.txt` or `.md` files here. On ingest they are chunked, stored as
`sources` (kind = `corpus`), embedded, and become retrievable evidence for AI
claims — exactly like web-search results, but always available offline.

Good things to add for the Retail Banking demo:
- public "AI in banking" / "future of work in financial services" reports
  (e.g. from regulators, consultancies, industry bodies)
- a KYC/AML process description
- a bank's published operating-model or role taxonomy

If this folder is empty and `ENABLE_WEB_SEARCH=false`, AI findings are still
produced but are labelled as reasoned-from-domain-knowledge rather than
evidence-backed.
